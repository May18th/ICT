由 `deploy/nexent/` 真机评测流程生成，**不要手改**。

- 日期：2026-11-13
- 平台：本机 Nexent v2.7.0（Docker 全栈在线，`urban-twin-mcp` healthy）
- 评测对象：跨片区抽排资源分配策略（`decision_poc.allocation.decide()`）
- 评测机制：**Nexent 原生 Agent 评测**（评估器 + 评测集 + Judge 模型），非离线自算

---

## 0 一句话结论

在 Nexent 平台上，用**平台原生 code 评估器**对同一份冻结 12 例评测集跑两次评测，
分别对应进化前策略（v1）与进化后策略（v1.2），结果：

**综合得分 0.7763 → 1.0000；通过率 9/12 → 12/12。**

平台自己的 LLM 根因分析对进化前版本的诊断是"资源分配与调拨逻辑失效、跨区协同能力缺失"，
对进化后版本判定"全部 12 个测试用例均通过"。

---

## 1 评测设计（为什么这样测才可信）

赛题 3 要求"进化验证基于平台原生评测机制"。本评测按此落地：

| 环节 | 实现 |
| --- | --- |
| 反馈源（ground truth） | 冻结 12 例（8 train + 4 holdout），`samples/eval/allocation_cases.json`，逐例带依据条款 |
| 评测集 | Nexent `/api/evaluation-sets`：`allocation_v1`（set_id=1）与 `allocation_v12`（set_id=2），各 12 例 |
| 评估器 | Nexent `/api/evaluators` 的 **code 类型**评估器（evaluator_id=16「内涝抽排分配偏差v3」），复刻 `decide()` 确定性算法与 `DEVIATION_WEIGHTS` 加权偏差公式 |
| Judge 模型 | DeepSeek-Chat（model_id=5，平台 `connect_status=available`） |
| 策略版本注入 | 通过评测集 query 的 `policy` 字段区分 v1 / v1.2，评估器据此选择策略参数 |

关键设计：评估器**复刻** `decide()` 而不是让 LLM 现算，保证同一输入逐位一致，
使平台评测结果能与离线冻结报告（训练偏差 0.2264→0）**互相印证**。

分数语义：`score = 1 - 加权决策偏差`，偏差 0（完全对齐 ground truth）即满分 1.0。

## 3 逐用例明细

进化前（v1）在需要跨区调拨的 6 例上全部失分——v1 的默认策略是"各片区只用本区库存、
不做跨区调拨"，遇到"关键片区本区不足、低风险片区有富余"的场景就分配错误：

| 用例 | v1 偏差 | v1.2 偏差 | v1 的错误 |
| --- | --- | --- | --- |
| T1 实况资源紧张 | 0.3171 | 0.0000 | 未从 B-01 调 1 台给关键 A-03 |
| T2 缺口扩大 | 0.5229 | 0.0000 | A-03 只分 2 台（应 5），未调 3 台 |
| T3 反向关键 | 0.5943 | 0.0000 | 未从 A-03 调 3 台给关键 B-01 |
| T6 仅危险源关键 | 0.3771 | 0.0000 | 未从 B-01 调 2 台给有燃气影响的 A-03 |
| H1 留出·关键缺口 | 0.3083 | 0.0000 | 未从 B-01 调 1 台 |
| H2 留出·反向 | 0.5643 | 0.0000 | 未从 A-03 调 2 台给关键 B-01 |

进化后（v1.2）通过 `weight_closure=1.0` + `weight_hazard=0.25` + `transfer_penalty=0.1`
把"封路阈值 + 危险源"纳入优先序、允许低风险片区让出库存，12 例全部偏差归零，
跨区调拨方向与 ground truth 逐例一致（如 T1：B-01→A-03 1 台；T3：A-03→B-01 3 台）。

## 6 表述边界（答辩必须按此口径，不得夸大）

- 本评测的"进化"发生在**确定性分配算法层**（`decide()` 的策略参数），不是 LLM 模型的
  参数微调或在线学习。这是诚实的边界：进化 = 策略参数受控迭代，由平台原生评估器验证。
- 评测 run 中 Agent（`urban_deduction_agent`）被平台调用执行 query，但评分由 code 评估器
  对确定性算法输出计算——**不引入 LLM 作答噪声**，这正是数字能对齐离线冻结报告的原因。
- 评测集是受控合成场景（12 例），不是真实市政数据回流。
