# Twin3D 深度事件镜像设计

## 目标
将 `/twin3d` 从自动循环动画升级为可解释的事件镜像：用户既能完整查看六跳推演，也能点击积水、泵站、道路和封路对象追踪其状态与证据。

## 目标范围
- 六跳时间轴：播放、暂停、上一跳、下一跳、重播。
- 对象选择：点击对象显示详情、关联跳次和 ActionCard。
- 空间联动：当前跳次高亮相关道路、积水、泵站和封路状态。
- 证据面板：展示输入证据、判断依据、执行动作、结果证据，并区分模拟与已确认状态。
- 主页面联动：沙盘与主页面共用 scheduler 数据，不复制业务状态。

## 最终拓展方向
以下内容不纳入本轮制作，但作为后续版本路线保留：
- 增加更复杂的三维资产、电影化运镜和多视角演示。
- 接入真实生产系统、实时传感器和现场反馈。
- 扩展为多场景、多事件并行推演。

## 约束
- 继续使用现有 Python 内嵌 HTML、Three.js、本地资源和 `/api/scheduler`。
- 所有对象 ID、状态和证据必须来自现有数据或明确标记为演示状态。
- 默认视角保持全景；详情面板按需展开，不遮挡主要沙盘。

## 验收
- 首屏 5 秒内可识别当前事件阶段。
- 六跳可手动逐跳浏览且空间状态同步。
- 点击对象可看到对象详情、状态变化和关联跳次。
- 浏览器控制台无 JavaScript 错误；现有测试与编译检查通过。
