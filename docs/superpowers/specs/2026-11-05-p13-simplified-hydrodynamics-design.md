## 1 为什么现在补

P12 定量层只有**稳态**口径：推理公式产流、曼宁满流能力、恒定净流量的积水上涨速率。
这套口径能回答"还差多少流量""再多久到阈值"，但回答不了三类问题：

| 问题 | 稳态口径为什么答不了 |
| --- | --- |
| 泵站**停机**后前池水位怎么走、什么时候到警戒水位、超警多久 | 给的是"上涨速率"，没有水位过程线与启停切换 |
| 上游来水过程线经过管段/河段后**峰值削减多少、峰现滞后多久** | 满流能力是定值，不含槽蓄与楔蓄 |
| 调蓄空间（下沉广场、基坑、前池）**蓄满漫溢**的过程 | `ponding_forecast` 假定面积不变、净流量恒定，无库容曲线与溢流 |

A3 这条缺口之前被明确标注为"水动力计算（本场景明确不做）"。本轮把其中**可离线、可复核、
不含未率定几何假设**的部分做成内核模块，其余仍不做——见 §2。

## 2 做的是什么，不是什么

**做**：集总式简化演进，两种经典方法，参数全部由调用方给出：

1. **马斯京根法（Muskingum）**：线性槽蓄演进，给出出流过程线、峰值削减率、峰现滞后；
2. **修正 Puls 法（Modified Puls / storage-indication）**：按库容曲线做调蓄演进，给出水位过程线，
   可叠加恒定抽排能力与溢流堰，用于前池停机/复机、下沉空间蓄满过程；
3. **过程线查询**：到指定水位的时刻、超阈值累计时长，均按离散过程线线性插值给出。

**不做**（边界不变，理由不变）：

| 不做 | 原因 |
| --- | --- |
| 圣维南非恒定流完整方程、2D 浅水、1D/2D 耦合内涝推演 | 需 EPA SWMM 级模型 + 率定数据；硬做就是假精确 |
| 泵特性曲线 H–Q、局部损失、跌水/倒虹 | 台账没有这些数据，输出一律 `uncomputable` |
| 把演进塞进六跳主循环迭代求解 | 时延不可控；本层只提供"给定过程线算过程线"，组合由上层做 |

**口径必须说清**：这是"过程线级别的一阶近似"，不是"水动力模型的替代品"。
马斯京根的 K、X 与库容曲线都不是本工程实测/率定值，因此每个结果的 `assumptions` 与
`error_bound` 必须写明"未率定"，禁止在答辩里把本层输出说成 SWMM 级推演。

## 3 公式与出处

### 3.1 马斯京根汇流

槽蓄方程 `S = K·[X·I + (1−X)·O]`，与连续方程联立、按时段差分后：

```
D  = K·(1−X) + Δt/2
C0 = (Δt/2 − K·X) / D
C1 = (Δt/2 + K·X) / D
C2 = (K·(1−X) − Δt/2) / D
O₂ = C0·I₂ + C1·I₁ + C2·O₁          （C0 + C1 + C2 = 1）
```

- K：传播时间（h）；X：楔蓄权重（0 ≤ X ≤ 0.5）；Δt：计算时段（h）；
- **稳定性条件** `2·K·X ≤ Δt ≤ 2·K·(1−X)`：不满足时 C0/C2 会变负，演进会造出不物理的
  负出流或振荡，因此直接返回 `uncomputable` 并给出原因，不用负系数硬算；
- 初始时段按稳态起算（`O₁ = I₁`），这是缺初始出流的唯一诚实处理；
- 出处：工程水文学教材与 USACE HEC-HMS 技术参考手册的通用方法，**K、X 本工程未率定**。

### 3.2 修正 Puls 法调蓄演进

连续方程与槽蓄关系的 storage-indication 形式：

```
S(h₂)/Δt + O(h₂)/2 = S(h₁)/Δt − O(h₁)/2 + (I₁ + I₂)/2
O(h) = Q_抽排(h) + Q_溢流(h)
Q_溢流(h) = C·b·max(0, h − h_堰顶)^(3/2)   （宽顶堰，C 取 1.7，SI，m³/s→m³/h 换算）
```

- `S(h)` 由**调用方给出库容曲线**（水位序列 + 对应库容序列，均严格递增），本层不内置几何假设；
- 左边 `S(h)/Δt + O(h)/2` 对 h 严格单调递增，用二分法求每个时段的末水位（不引入第三方依赖）；
- 抽排能力允许给标量（恒定）或与入流等长的序列（停机/复机等启停情景）；
- 求出的水位超出库容曲线上限即判定"漫溢”，返回 `uncomputable` 并指出越界时段——
  不截断、不外推库容曲线；
- 出处：修正 Puls 法（storage-indication）为水文计算通用方法；堰流系数沿用 `hydraulics.py` 的经验值。

### 3.3 过程线查询

- **到阈时刻**：过程线按相邻时段线性插值，给出首次上穿目标水位的时刻；
- **超阈时长**：首次上穿与随后首次下穿之间累计时长；若始终未回落，则从首次上穿到过程线末尾；
- 离散误差 ≤ 一个计算时段 Δt，写入 `error_bound`，不假装连续解。
