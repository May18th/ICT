### 3.1 「DSR / DCR」到底是什么 —— 源码核对结论

讲师口语说的「导出 DSR 描述语句 / DCR 文件」在平台上**没有同名格式**。实际实现是 `[源码 backend/management/services/agent/management.py:1410 export_agent_with_skills_impl]`：

- Agent 带 Skill 时导出一个 zip：`<agent_name>.zip`，内含 `agent.json`（`ExportAndImportDataFormat`）+ `skills/<skill_name>.zip`
- 不带 Skill 时直接返回 `agent.json` 的 dict
- 对应接口：`POST /agent/config/export`（`backend/apps/agent_app.py:653`）

**行动指引**：别去搜 "DSR 文件"。到平台 Agent 配置页右键 →「导出」，拿到 `<agent_name>.zip`，解压核对 `agent.json` + `skills/` 两个技能包是否齐全，这就是初赛要交的「配置能力」证据。

## 4 平台能力边界（直播讲、影响方案设计的几条）

- 硬件：本地跑数据处理**至少 4 核 16G 起步**，内存要富余，否则会出现文件处理不了 `[直播 10:40]`。部署用 Docker；K8s 只在企业级才需要 `[直播 10:12]`。Windows 需 Docker Desktop + WSL2 `[直播 23:00]`。
- 多智能体：主从模式，配「协作智能体」做分配 `[直播 02:05 / 25:20]`。
- 记忆：租户级 / 用户级 / 会话级三层，会话中记录可查可改 `[直播 09:26]`。
- 运行策略：ReAct + Plan 模式，支持流式输出 `[直播 07:16]`。
- 模型接入：推荐模型之外，兼容 OpenAI 原生接口的外部模型；私有协议需改源码 `[直播 06:40]`。支持重排与多模态模型。
- 知识库：多种格式文档接入，可做文档现代化处理（chunk 化），支持接第三方知识库 `[直播 07:35]`。
- 角色：超级管理员 / 租户管理员 / 开发者三级 `[直播 09:56]`。
- 官方立场：**PPT 内容与官方文档一致，文档比 PPT 更详细，建议直接看文档** `[直播 26:04]`。开发资料入口 = GitHub + GitCode 同一份代码 + 官网文档 + 每月月初开源例会 `[直播 15:22 / 15:49]`。
