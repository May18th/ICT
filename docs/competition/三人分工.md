## 2. 队友 B —— 演示线（产出：3 分 40 秒录屏，带字幕）

### 唯一依据：`docs/competition/录屏分镜.md`

7 个镜头，每个镜头的字幕**逐字写死**，照念或照打，不要改写。假设观众**静音、不懂排水、不是成都人**。

### 前提：必须在能打开演示服务的机器上录

```powershell
cd "D:\华为ICT\agent_poc"
$env:PYTHONPATH = "src"
.venv\Scripts\python.exe -m decision_poc.web_demo --port 8790
```

Git Bash 用：`PYTHONPATH=src .venv/Scripts/python.exe -m decision_poc.web_demo --port 8790`

**必须在项目根目录执行**。直接敲 `python -m decision_poc.web_demo` 会报找不到模块。

启动后浏览器打开 `http://127.0.0.1:8790`。

**如果 B 不在开发机上**：让开发同学录画面（他最快能判断"画面对不对"），
B 只做后期加字幕 + 转码。这比远程连机器省事，也不容易出错。

### 加字幕

- 位置：画面下方 1/6 处，深色半透明条 + 白字
- 字号：约屏高的 1/22
- 节奏：一段停 3 秒以上，不要滚动字幕

### 自检（必须做）

1. **关掉声音**从头看一遍——能看懂吗？
2. 镜头 3（凭什么信）的台账原文，看得清吗？
3. 镜头 4（平台真机）有没有停留超过 3 秒在原始 JSON 上？
4. 全片有没有出现 `ORG-` / `DF-PS-` / `WO-` 这类英文代号？出现就重录那一镜
5. 时长 ≤ 3 分 40 秒（超过 4 分钟评委会跳着看）

### 交付物

一个 `.mp4`，1920×1080，带硬字幕（不要外挂字幕文件，很多平台不认）。

## 3. 你（负责人）—— 实证线 + 终审

### 不做的两件事（2026-11-14 定）

原来的「业务价值实测」和「真实用户评分」**不做了**，理由不是偷懒：

- 使用者是个位数（区应急值班 + 我们），凑 3–5 人打分是**为了有个数而造数**；
- 这是初赛，评审看的是「说得清、核得动」，不是运营数据；
- 硬凑出来的"省 60% 人力"被问一句"谁计时的、几人次"就穿。

`delivery_check.py` 里这两项已经**移出判据**，标成「范围外（初赛不计）」：
照实显示现状（0 样本 / 6 行空），但不进判决、不扣分。

**但价值叙事仍然要写**——初赛评审维度里「业务价值」占 25%，只是不靠百分比讲。
用可复算的数：

| 可写的 | 出处 |
|---|---|
| 跨区调拨提前 40 分钟 | 事件时序（08:30 封路通告 → 09:10 调泵到位） |
| 绕行代价 3040 米 | 路网台账算的最短绕行 |
| 移动泵缺口 2 台 | 资源库存 vs 需求 |
| 8 个部门、7 步时序 | 协同编排结果 |

**红线**：不写「省人力 X%」「省时间 X 分钟」「完全离线」「模型精度 2.4%」。

### 第 1 件：终审

A、B 的产出都到齐后，跑一次：

```bash
python scripts/delivery_check.py --full
```

技术组 + 材料组全绿 = 可以交（范围外那组不参与判决）。
