## 渲染版本：P8（当前唯一基线）

两条素材都从 `blender/2026-11-04-VD02-P8-align.blend` 渲染（P8 = 材质/渲染档位，不动几何）。整条链：
`build_p6_look.py`（立面+湿路面）→ `build_p6_env.py`（天际线背景+店面分层+水面+藏电线杆）→
`build_p7_final.py`（色带压暗+立面 Bump/色差+围挡水尺条纹）→ `build_p8_align.py`（立面烘世界对齐 UV，
窗格贴图改 UV 投影，窗格列/行对齐几何窗带）；`render_p5_incident.py` 负责机位/氛围/水面涟漪/雨丝下落动画。

- 楼体：`win_grid_lit.png` 窗格立面 + 3 个色差变体 + Bump，屋顶按法线混回素混凝土，含少量暖色亮窗；
- 背景：`VD02_BG_*` 换天际线贴图（纯自发光，雨雾里墙顶硬边消失——上一版"大暗墙"已修掉）；
- 地面：湿沥青（Asphalt033 + rough 0.42，86 个地面块）；
- 雨：主雨层 24,000 条 + 低洼点近景雨层复制件 6,000 条。
