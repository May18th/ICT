# 华为 ICT 创新赛赛题 3 项目方案与实施计划

## 目标
面向城市基础设施管理，构建可在华为 ModelEngine Nexent 上运行的多模态异构数据资产认知智能体，完成城市基础设施数字孪生语义层、跨部门事件推演、AI 数据可信溯源、低资源知识图谱本体半自动构建、MCP + Skills 编排和可溯源决策，并沉淀可复用 Skill 工作流模板。

## 方案主线
用户输入城市事件、设施变化或跨部门协同问题后，系统执行：

1. 接收文本、表格、地图/管线图、图片和事件报告等异构数据；
2. 进行解析、清洗、切片、实体与关系候选抽取；
3. 通过少量领域样本和人工确认生成城市基础设施事件本体；
4. 将知识检索、证据对齐、图谱查询、规则检查封装为 MCP Tools；
5. 通过 Nexent Skills 编排“检索 → 图谱定位 → 跨文档多跳推理 → 风险判断 → 建议生成”；
6. 输出结论、证据来源、推理路径、知识版本和可执行建议；
7. 对人工反馈进行评测，形成 Skill 和知识库迭代记录。

现有决策 PoC 保留为末端的决策契约、审批门禁、证据校验、评测和版本回滚模块，不再作为项目展示主线。

## 目标演示场景
城市道路、排水、供电、燃气和通信等基础设施发生联合事件，例如暴雨导致道路积水并影响地下管线施工。智能体综合管线图、道路施工计划、维修工单、气象信息、应急预案和资源清单，识别受影响对象、部门职责冲突和资源缺口，推演跨部门处置路径，并为每个判断提供数据来源、版本和推理链路。

## 技术架构
- 数据层：文本、CSV/Excel、地图/管线图、图片、PDF/扫描件；统一元数据、版本、权限、时间有效期和来源。
- 认知层：文档解析、表格结构化、地图/图像特征摘要、实体关系抽取、候选本体生成、人工确认。
- 知识层：本体、实体、关系、证据片段、版本和冲突记录；先采用可复现的轻量图存储，后续按 Nexent 环境适配。
- 编排层：Nexent Agent + MCP Tools + Skills；工具只提供受控能力，流程由 Skill 编排。
- 推理层：关键词/向量检索、图谱邻接扩展、跨文档证据合并、多跳推理、规则与风险判断。
- 展示层：可视化 Demo，展示问答结果、证据卡片、推理链路、图谱路径和 Skill 执行步骤。
- 评测层：检索命中、实体关系准确率、路径正确率、引用完整率、答案正确率、响应时间和人工采纳率。

## 交付阶段

### 阶段 0：范围冻结
- 确定城市基础设施事件推演作为主场景。
- 固定 1 个核心演示问题和 3 个扩展问题。
- 明确数据许可、脱敏规则和可开源范围。
- 明确 Nexent 版本、可用 MCP 接口、部署环境和 Demo 访问方式。

### 阶段 1：数据集与基线
- 整理管线图、道路施工计划、维修工单、气象信息、应急预案和资源清单。
- 建立统一数据目录、元数据和版本字段。
- 编写解析、清洗、切片和样本标注脚本。
- 建立人工标注集和最小评测集。

### 阶段 2：本体半自动构建
- 定义道路、管线、设施、区域、事件、部门、职责、资源、预案、处置动作、风险等级等概念。
- 从少量标注样本抽取实体、关系和属性候选。
- 生成候选本体和候选三元组。
- 提供人工确认、拒绝、合并和版本发布流程。
- 记录每个知识项的来源文档和证据片段。

### 阶段 3：MCP + Skills
- 实现数据资产检索、知识图谱查询、证据详情、冲突检测、风险规则和结果追踪工具。
- 编写可复用 Skills：资产检索、事件影响分析、资源冲突检查、跨部门推演、证据审计。
- 在 Nexent 中配置工具权限、输入输出契约和失败处理。
- 验证 Skill 可以独立复用、组合和替换。

### 阶段 4：跨文档多跳推理
- 实现“事件现象 → 受影响设施 → 责任部门 → 资源需求 → 处置动作 → 后续风险”的多跳路径。
- 强制输出引用文档、页码/行号/记录 ID、知识版本和推理路径。
- 对证据不足、证据冲突和知识过期进行安全停机或转人工。
- 接入现有决策契约和审批门禁。

### 阶段 5：可视化 Demo 与评测
- 完成问答界面、证据面板、图谱路径面板、Skill 执行轨迹和人工确认界面。
- 建立离线评测集和自动评测脚本。
- 形成量化指标基线、改进前后对比和失败案例集。
- 完成 Nexent 环境可运行验证和一键复现说明。

### 阶段 6：比赛材料
- 初赛：模板 1 作品信息收集表、项目 PPT，覆盖背景价值、创新性、数据集处理、关键代码和量化指标。
- 决赛：模板 2 答辩 PPT、可视化 Demo 地址、完整代码、数据集、README、部署说明、复现脚本和开源截图。
- 准备 5 分钟/10 分钟演示脚本、评委追问答案和异常演示。

## 建议量化指标
- 数据资产解析成功率 ≥ 95%。
- 实体识别 F1、关系抽取 F1、本体候选采纳率分别建立基线并持续提升。
- 检索 Top-k 证据命中率 ≥ 85%。
- 多跳路径正确率 ≥ 80%。
- 结论引用完整率 100%。
- 冲突或过期证据拦截率 100%。
- 端到端演示响应时间 ≤ 30 秒。
- 人工确认后的维护建议采纳率作为应用价值指标。

## 总体验收门槛
- Nexent 上能运行完整 Skill 工作流；
- 至少一个真实可复现的制造业运维案例闭环；
- 输出答案、证据和多跳路径可追溯；
- 本体构建过程包含自动候选和人工确认；
- MCP 工具和 Skill 模板可复用；
- 代码、数据、README 和 Demo 可按文档复现；
- 评测指标、失败案例和改进证据齐全。
